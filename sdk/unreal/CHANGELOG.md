# Changelog

All notable changes to the Chill Unreal SDK are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
package version tracks the coordinated repository release.

## [0.1.0] - 2026-09-07

### Added

- Initial source-only Unreal Engine plugin with the semantic capture surface:
  actions, events, impressions, activities and pages.
- Consent-gated capture with a crash-safe durable queue and OTLP/HTTP delivery
  through a game instance subsystem.
- Annotation allow-list with privacy classifications carried on the wire.
