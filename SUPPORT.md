# Support

Chill is an early-stage open-source project maintained on a best-effort basis.
There is no guaranteed response time, compatibility window, hosted service, or
commercial support commitment.

- Use GitHub Discussions for setup questions, design conversations, and ideas.
- Use the issue forms for reproducible defects and scoped feature requests.
- Read the component guides in `docs/`, `backend/`, `sdk/`, and `deploy/`
  before filing a request.
- Follow `SECURITY.md` for vulnerabilities; never disclose them in public.

Include the Chill revision, operating system, toolchain versions, relevant
component, exact command, and sanitized output. Remove credentials, tenant
identifiers, personal data, telemetry payloads, and private endpoints.
